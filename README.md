# The Floor Is Lava

The floor is lava and it's rising! Climb the furniture (couches, shelves, lamps, trampolines) to the balloon at the top before the lava gets you. In each round the first to the balloon scores 10, then 7, 5, 4, 3, 2, 1; anyone the lava catches comes after them, ranked by how high they got.

**How to play:** run with A / D, the arrow keys or the on-screen stick, jump with Space, W or Up (hold to jump higher), press S or Down to drop through a piece of furniture. Up to 12 players; bots fill the table to 6. The host picks 1, 3 or 5 rounds and how fast the lava rises.

Play it at https://onceworlds.com/play/floor-is-lava

Plain JavaScript modules and Canvas 2D, no build. `npm test` runs the tests (rules, the tower for 250 seeds, bots, bot-only matches, the host's rounds, and the real page against a fake browser). MIT licensed.
